# Contributing

Fork the repository, create a focused branch, and run `npm install` and `npm test` using Node 22.13+. Add regression tests for behavior changes and document new public interfaces. For a new Mode, include native definitions, dependencies, usage examples, tests and license information. Never commit customer data, credentials or private research.

Open an issue before substantial runtime, syntax or architectural changes. Submit a pull request describing the problem, solution, compatibility risks and test evidence. Keep changes small and reviewable. Sign off each contribution using `git commit -s`; see DCO. This certifies your right to contribute, not cryptographic signature verification. Contributions are submitted under Apache-2.0. Maintainers review and merge after checks pass; passing tests alone does not establish correctness.

# ic3o RFC process

An RFC is a proposal, not an approved change. Open a GitHub issue using the RFC template or reference an existing RFC issue. Discuss alternatives and acceptance criteria before implementing. Once scope is agreed, submit a numbered Markdown RFC in this directory using TEMPLATE.md. Maintainers record the decision and rationale in the issue and RFC. Accepted RFCs do not waive tests, security review or compatibility obligations.

Statuses: proposed, accepted, rejected, superseded, withdrawn. Assign numbers during maintainer review; do not reserve them independently.

ic3o is an open-source framework for recursively composed, contract-governed applications. Start with a small network. Reuse the pieces that already exist. Share the pieces that others can use.

What makes an ic3o application different?

Instead of treating a program as an opaque operation, define its inputs, the meaning of its information, the obligations it must satisfy, the implementation it invokes and the destinations for its results. An implementation can itself be another network.

Framework, engine and contributor tooling

ComponentResponsibility
ic3oNative framework and network definitions; the public preview includes a deterministic runtime.
ThICCCA separate execution engine that can run ic3o networks and provide probabilistic routing via Jev Bridges. Not required for this preview.
gh-ic3oGitHub CLI extension for synchronizing, building, inspecting, testing and contributing.

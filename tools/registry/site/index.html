How the contributor program works

What you gain

  • Applications in your own GitHub repositories.
  • Publicly attributable PRs and reusable work.
  • More capabilities for your next project.

What the framework gains

  • Reusable Modes and capabilities.
  • Reproducible reports of core limitations.
  • More real applications exercising shared infrastructure.

Quickstart

From GitHub identity to a tested native application.

1. Install

Install Git, GitHub CLI and Node 22.13+. Native Windows extension installation is not yet verified.

gh auth login
gh extension install Affect-Dynamics/gh-ic3o
gh ic3o sync
gh ic3o

Sync executes trusted upstream tests before activating the framework and bundled registry.

2. Build and test

gh ic3o init my-app
gh ic3o test my-app/pep/my-app.pep
gh ic3o run my-app/pep/my-app.pep quantity=2 price=5
my-app/
├── pep/my-app.pep
├── context/my-app.context
├── contract/my-app.contract
├── fixtures.json
└── README.md

Expected output

total: 10

The starter contract rejects negative inputs and guarantees the total.

3. Publish your work

Review files and exclude secrets. Choose visibility explicitly.

cd my-app
git init -b main
git add .
git commit -s -m "Initialize application"
gh ic3o repo my-app --private

4. Stay synchronized

CommandPurpose
gh extension upgrade ic3oUpdate launcher
gh ic3o syncVerify and activate runtime and registry
gh ic3o rollbackRestore runtime, not application data

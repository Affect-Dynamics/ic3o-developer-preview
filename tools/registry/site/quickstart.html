Install and first run

Get from a GitHub identity to a tested native network without cloning the framework.

On this pageBefore you start1. Install and authenticate2. Synchronize the framework3. Create and execute a project4. Explore the contributor dashboard5. Stay synchronized6. Publish only when ready

Before you start

Install Git, GitHub CLI and Node.js 22.13+. Use a terminal with all three commands on PATH. Native Windows extension installation is not yet verified.

git --version
node --version
gh --version

1. Install and authenticate

gh auth login
gh extension install Affect-Dynamics/gh-ic3o
gh ic3o whoami

Authentication is handled by official GitHub CLI. The extension does not need you to paste a GitHub token into an ic3o configuration file.

2. Synchronize the framework

gh ic3o sync
gh ic3o status

Sync fetches the framework and bundled registry, runs upstream tests for a new snapshot and activates the revision only after verification. Status reports active and previous Git commits. Treat upstream code as trusted code.

3. Create and execute a project

gh ic3o init my-app
gh ic3o test my-app/pep/my-app.pep
gh ic3o run my-app/pep/my-app.pep quantity=2 price=5

Expect two passing fixtures, followed by JSON output with total 10, a response delivery and a trace. Continue to the hands-on tutorial to understand the files and exercise a failed guarantee.

4. Explore the contributor dashboard

gh ic3o dashboard

Browse the registry, register a local application or inspect a bundled example. Use the dashboard to discover definitions, and the CLI to validate and reproduce executions.

5. Stay synchronized

gh extension upgrade ic3o
gh ic3o check
gh ic3o sync
gh ic3o status

The extension and runtime snapshot update independently. Rollback restores the previous installed runtime revision, not app data. See CLI reference for details.

6. Publish only when ready

After inspecting your project and excluding secrets, initialize Git if needed and commit with your own identity. Choose private unless you intend to share the source.

cd my-app
git init -b main
git status
git add .
git diff --cached
git commit -s -m "Initialize application"
gh ic3o repo my-app --private

Use the contribution guide to distinguish publishing your own app from submitting shared infrastructure upstream.

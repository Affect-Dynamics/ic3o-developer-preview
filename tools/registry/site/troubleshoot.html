Troubleshooting

Diagnose the layer that failed before changing your application or reporting a framework issue.

On this pageInstallation and synchronizationDefinition errorsCollect evidenceReport a reproducible limitation

Installation and synchronization

SymptomWhat to check
gh: command not foundInstall official GitHub CLI; restart the shell.
Node 22.13+ requiredCheck node --version and the Node selected by PATH.
Run gh ic3o sync firstRun sync from a trusted environment.
Snapshot changedDo not patch the active snapshot. Preserve app files and investigate modifications; use a clean installed revision or a separate development checkout.
Sync already running or stale lockConfirm no sync process is running before removing a stale lock. Do not remove a live lock.
Candidate verification failedCheck the actual test failure. The previous active revision is retained; run without an automatic update or roll back if appropriate.

Definition errors

SymptomWhat to check
Missing default context / contractCheck matching filenames and sibling directories, or declare explicit references.
Unknown valueCheck variable spelling and supported expression grammar. Compound arithmetic is not supported.
Ambiguous referenceQualify the Mode or use an explicit relative path.
Unresolved capabilityInspect local registry and Modes. A missing binding does not trigger AI discovery.
Wrong typeCheck Intake types and CLI key=value values.
Require failedInput violates a live precondition.
Guarantee failedImplementation result fails a declared obligation. Do not remove the contract merely to get a passing test.

Collect evidence

gh ic3o status
gh ic3o inspect pep/my-app.pep
gh ic3o validate pep/my-app.pep
gh ic3o test pep/my-app.pep

Record the exact input, expected and observed behavior. Structural validation can pass while a live guarantee fails. A fixture pass proves only its scenario.

Report a reproducible limitation

Remove customer data, credentials and private research. Include the active revision, smallest native network, execution command, expected behavior and actual output. Then run gh ic3o report or open an issue. For an architectural proposal use the RFC template ↗.
